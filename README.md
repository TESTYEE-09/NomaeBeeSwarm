# NomaeOS Public Release Builder

This public repository builds the NomaeOS preview ISO without consuming private-repository GitHub Actions minutes.

The maintained source of truth remains `TESTYEE-09/NomaeOS`. Release assets produced here are linked back from that repository.

NomaeOS is a NomaePC console operating-system image based on Bazzite Deck for the Jonsbo C6 Nomae Box prototype.
